The main purpose of this program is to demonstrate a ping program using datagram socket programming which supports Ipv4 and Ipv6 network address. It also has a function to generate ICMPv4 packet for Ipv4 address. In this program, it will generate Ipv6 packets based on data size and packet rates per second and calculate the round trip time of the packets, within certain time duration given by user. The packet data payload also based on a hexadecimal value given by the user. Each message also will be given a unique ID which is automatically generated by the system. All results for sending, receiving, message ID, payload length, payload value (from hexadecimal convert to decimal) and round trip time (in milliseconds) for each packet will be printed on the screen text area.
